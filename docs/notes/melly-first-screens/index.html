Melly · 화면 설계 · 2026.07.15

로그인 다음에 팬이 찾아야 할 화면

직접 설계한 로그인 화면과 팬미팅 목록 화면에서 처음 방문한 팬의 동선을 잡았다.

처음 그린 두 화면

팬이 서비스를 시작하는 로그인 화면과 참여할 행사를 찾는 팬미팅 목록 화면을 직접 설계했다. 첫 화면에 들어오는 일과 입장한 뒤 행사를 고르는 일을 연달아 놓고, 팀에서 구현할 서비스의 출발점을 화면으로 공유했다.

시안과 후속 구현을 구분해 돌아보기

나중에 당시 산출물과 직접 맡은 화면을 다시 대조했다. 프로젝트 소개에 실은 홈 화면은 이후 개발 미리보기이고, 이날의 설계 결과는 로그인과 팬미팅 목록 두 화면이었다. 두 시점을 나누니 화면 설계와 이후 API 연동에서 각각 무엇을 맡았는지 설명할 수 있었다.

당시 작업을 2026년 11월 20일 정리한 글입니다.

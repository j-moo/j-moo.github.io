계정은 생겼는데 왜 가입을 다시 해야 할까?

가입과 첫 소비 기록 사이에서 계정·프로필 저장과 기본 카테고리 생성을 따로 점검했다.

가입 다음 화면에서 발견한 문제

가입 오류와 카테고리 목록이 비는 현상을 보고, 팀원과 만든 ERD를 실제 모델과 대조해 달라고 요청했다. 사용자 행이 생겨도 프로필이 준비되지 않으면 가입을 마칠 수 없었다. 테이블만 만들어 둔 카테고리 역시 사용자가 고를 항목을 제공하지 못했다.

저장의 경계를 정하다

AI와 함께 사용자와 프로필 생성을 한 트랜잭션으로 묶은 로직을 확인했다. 이메일 중복을 먼저 검사하고, 프로필 저장이 실패하면 사용자 생성도 되돌리게 했다. 기본 카테고리 8종은 별도로 초기화했다. 가입 화면을 검토할 때 다음 화면이 실제로 읽을 데이터까지 확인하게 된 계기였다.

당시 작업을 2026년 11월 20일 정리한 글입니다.

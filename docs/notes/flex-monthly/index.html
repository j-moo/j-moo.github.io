기록이 없는 달에는 무엇을 보여줘야 할까?

월별 소비 분석에서 입력이 비어 있는 경우와 외부 분석 호출이 실패한 경우의 처리를 나눴다.

분석에 들어갈 입력부터 확인하기

월별 소비 총액과 카테고리별 집계가 분석 요청에 들어가는지 확인했다. 사용자가 다시 들어왔을 때 지난 결과를 볼 수 있도록 분석 결과를 구조화해 저장하고, 최신 결과와 이전 결과를 조회하는 흐름을 검토했다.

사용자에게 다른 결과가 필요한 두 경우

기록이 하나도 없는 달에는 데이터가 부족하다고 알려야 한다. 이미 소비 내역이 있는데 외부 분석 호출이 실패한 달에는 그 집계로 규칙 기반 결과를 만들 수 있다. 두 조건을 나눠 검토하면서, 추천 문장보다 먼저 어떤 입력으로 만든 결과인지 설명할 수 있어야 한다는 기준을 세웠다.

당시 작업을 2026년 11월 20일 정리한 글입니다.

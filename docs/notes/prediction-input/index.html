DDUBI · 데이터2026.09.08 / 4분 읽기

모델을 바꾸기 전에 입력부터 다시 봤다

데이터가 많다는 것과 예측에 쓸 수 있다는 것은 달랐다. 연결률과 가용 시점으로 다시 살펴본 모델 평가.

좋아진 점수보다 먼저 확인할 것

버스 구간의 시간대별 평균 소요시간을 예측하던 중, 승객수 정보를 추가한 모델의 결과를 확인했다. 하지만 실제로 연결된 값은 0%였다. 열을 하나 더 만들었다는 사실만으로 그 정보가 모델에 반영됐다고 설명할 수 없었다. 학습량으로 안내된 전체 전처리 규모와 실제 모델이 본 표본 수도 서로 달랐다.

학습할 때와 사용할 때를 맞추기

과거 운행 자료로 학습하는 것과 과거 요약값을 예측 시점의 입력으로 조회하는 것은 다른 문제였다. 실제 예측 순간에 확보할 수 없는 자료가 들어가면 실험 점수만 좋아질 수 있다. 날씨의 당시 가용 시각을 확인할 수 없어 최종 모델 입력에서 제외했고, 시간 순서와 참조 범위를 다시 확인했다.

같은 검증집합에서 비교하기

학습 4,999,590행과 검증 999,894행을 고정해 과거 중앙값과 네 모델 후보를 비교했다. 기준선의 MAE는 27.612696초, 선택한 LightGBM은 26.043974초였다. 같은 자료에서 약 5.68% 감소한 결과다. 다른 지표까지 모두 가장 좋았다는 뜻은 아니며, 별도의 최종 테스트 결과와 이 개선율을 섞지 않았다.

남긴 기준

이 평가는 과거 버스 인접구간의 시간대별 평균값에 대한 오프라인 평가다. 개별 승객의 대기·환승을 포함한 전체 도착 정확도는 별도 문제다. 다음 평가에서도 어떤 입력이 실제로 연결됐는지, 언제 확보되는 값인지, 비교 대상의 조건이 같은지를 먼저 확인하려 한다.

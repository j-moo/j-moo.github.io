다른 PC로 옮겼더니 게시물 사진이 사라졌다

SQLite에 남은 파일 경로를 따라가며 다른 컴퓨터에서도 사진이 열리려면 무엇을 옮겨야 하는지 확인했다.

DB에 남은 것은 경로였다

다른 PC에서 게시물은 보이는데 사진이 열리지 않았다. 게시물의 경로가 가리키는 업로드 파일을 함께 옮기지 않으면, 같은 DB를 열어도 이미지를 읽을 수 없었다. 프로젝트를 건네받는 사람이 SQLite와 함께 사진도 가져갈 수 있게 해 달라고 요청했다.

새로운 업로드의 저장 방식

AI의 도움으로 새 업로드의 바이트를 BinaryField에 보관하고 응답에서 data URL로 전달하는 변경을 적용했다. 이 방식은 이미지 데이터만큼 DB와 응답이 커질 수 있다. 기존 경로의 유실 파일 복구나 동일 조건의 용량·지연 변화는 당시 검증 범위 밖이었다.

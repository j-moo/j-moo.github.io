DDUBI · 성능 측정 · 2026.09.11

같은 예측을 더 빨리 읽는 데 메모리가 얼마나 들었을까?

동일한 10개 구간에서 반복 호출 평균은 0.2370초 줄고 최대 메모리는 172.8MiB 늘었다.

모델을 그대로 두고 읽기 경로를 바꾸다

요청마다 같은 참조 표를 다시 읽는 경로에 256MiB 한도의 LRU 캐시를 두었다. 자주 읽는 Arrow 표를 재사용하되 한도를 넘는 표는 저장하지 않았다. 같은 모델과 입력을 사용해 읽기 경로가 예측값 자체를 바꾸지 않는지도 확인했다.

첫 호출과 반복 호출을 구분해 비교하다

Windows의 Python 3.12 환경에서 동일한 10개 구간을 사용했다. 조건마다 새 프로세스를 띄우고 첫 호출을 뺀 세 번의 평균을 비교했다. 1.8675초에서 1.6305초로 12.69% 줄었고 예측값 차이는 0초였다. 최대 작업 집합은 1,370.1MiB에서 1,542.9MiB로 늘었다. OS 파일 캐시는 초기화하지 않았으므로 이 값은 해당 로컬 반복 호출 조건에서 해석했다.

당시 작업을 2026년 11월 20일 정리한 글입니다.

응모를 껐는데 서버는 왜 정원을 요구했을까?

팬미팅 생성 요청의 400 오류를 필드 생략, 1명, 0명의 차이로 좁혔다.

문서대로 보냈는데 반복된 400

응모를 끄면 활성화 여부만 보내도록 바꿨는데도 요청이 거절됐다. 이미지 URL과 날짜 조건을 점검한 뒤에도 같은 증상이 남았다. 엑셀 문서를 다시 해석하는 대신 팀 백엔드의 요청 객체와 서비스 검증 코드를 함께 보자고 요청했다.

생략과 0은 다른 입력이었다

capacity를 생략하면 필수값 검사에서 거절되고 1을 보내면 응모 비활성화 규칙에서 거절됐다. AI와 함께 프런트 요청을 수정해 응모 기간은 null, 정원은 0으로 보냈다. 린트·타입 검사·빌드는 통과했다. 당시 자료에서 권한 있는 계정으로 생성에 성공한 응답까지는 확인하지 못했다.

당시 작업을 2026년 11월 20일 정리한 글입니다.

두 키링의 매칭이 빛과 진동으로 드러나는 순간

프로젝트 최종 발표에서 어디까지 보여줬는지, 전날 촬영한 앱 화면과 구분해 정리했다.

손에 들었을 때 확인한 것

최종 발표에서 두 키링이 서로를 만나 매칭되고 LED가 켜지며 진동모터가 도는 장면을 보여줬다. 케이스 밖에서 보이는 빛과 손에 전해지는 진동으로, 내가 담당한 기판·펌웨어·배선이 사용자에게 어떻게 전달되는지 설명할 수 있었다.

앱 화면이 보여 주는 다음 단계

키링에서 알림을 받은 뒤에는 각 사용자가 앱에서 제안을 확인하고 수락할 수 있다. 제안 수락과 채팅은 11월 17일 촬영 화면에 남아 있다. 포트폴리오에는 그중 수락 창을 발췌하고, 18일 발표에서 보여준 실물 반응은 별도 사진과 설명에 남겼다.

당시 작업을 2026년 11월 20일 정리한 글입니다.

Tingle · IoT · 2026.11.17

키링의 만남 기록을 지우지 않고 읽을 수 있을까?

재현이 어려운 매칭 실패에서 USB로 기기의 기록을 읽고, 조회 전후 저장 영역이 같은지 검사했다.

키링을 바꾸며 남은 기록을 읽다

두 키링의 반응이 다를 때 어느 쪽까지 만남을 확정했는지 알아야 했다. 현장 시험을 맡아 보드를 바꿔 보고, 데이터를 그대로 둔 채 USB로 기기 상태와 만남 기록을 조회할 수 있도록 요청했다. AI가 진단 기능 구현과 로그 분석을 도왔다.

출력 누락과 데이터 손실을 구분하다

긴 목록에서 일부 줄이 빠졌다. 로그를 넣는 속도가 출력 속도를 앞서는 문제를 찾아, 앞선 줄을 처리할 시간을 주도록 보완했다. 한 보드에서 전체 11건과 상대별 3건을 각각 세 번 읽고 상태를 두 번 조회했다. 여덟 번 모두 출력이 끝났고 등록·만남 저장 영역의 전후 해시가 같았다.

당시 작업을 2026년 11월 20일 정리한 글입니다.

프로젝트 소개

팬이 행사에 응모하면 당첨자에게 통화 순서가 주어집니다. 자기 차례가 되면 대기 화면에서 일대일 영상 방으로 들어갑니다.

내 역할
프런트엔드 · 화면 설계와 API 연동
팀 · 기간
팀 프로젝트 · 2026.07 – 08
사용 언어
TypeScript · Java
프레임워크
React · Spring Boot
도구·기술
LiveKit

로그인과 팬미팅 목록을 직접 설계하고 팬의 입장 화면을 팀 백엔드와 연결했습니다. 공식 개발 기간이 끝난 뒤에는 입장 오류를 재현하고 AI의 도움으로 분기와 회귀 테스트를 보완했습니다.

주요 기능 개발

팬미팅 탐색과 응모

로그인 뒤 참여할 행사를 찾는 과정을 기준으로 목록 화면을 설계했습니다. 행사 설정을 화면에서 바꾸면 API가 어떤 값을 요구하는지도 요청과 응답을 대조해 점검했습니다.

대기열에서 영상 방으로

입장 토큰으로 영상 방에 접속하고 행사 상태로 타이머와 종료 안내를 표시합니다. 두 정보의 역할을 나눠 팬에게 현재 상태와 다음 행동을 안내했습니다.

트러블슈팅

토큰은 정상인데 영상 방이 열리지 않았다

문제
상태 조회 한 건만 실패해도 유효한 입장 토큰을 받은 팬의 화면이 멈췄습니다.
원인과 해결
Promise.allSettled로 두 요청의 결과를 따로 판정했습니다. 토큰이 유효하면 접속을 시도하고 상태 조회 오류를 안내한 뒤 3초 간격으로 다시 조회합니다.
확인 결과
상태 요청만 실패시킨 회귀 테스트에서 영상 방과 오류 안내가 함께 표시되는 것을 확인했습니다.

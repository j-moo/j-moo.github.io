Tingle

스친 만남을 빛과 진동으로 알리는 키링

프로젝트 소개주요 기능 개발트러블슈팅

프로젝트 소개

가까워진 두 키링이 서로의 조건에 맞으면 빛과 진동으로 알립니다. 양쪽 사용자가 앱에서 제안을 수락하면 대화를 시작할 수 있습니다.

내 역할
IoT · 키링 조립 및 기기 연동
팀 · 기간
6인 팀 · 2026.10.05 – 11.18
사용 언어
C · Kotlin · Java
프레임워크
Compose Multiplatform · Spring Boot
도구·기술
PostgreSQL · Zephyr RTOS · BLE / GATT

키링의 통신 조건을 정하고 연결선을 직접 압착해 기판과 케이스를 조립했습니다. 팀과 앱·서버를 연결하고 실물에서 증상을 재현했습니다. 펌웨어 변경과 검사 코드에는 AI의 도움을 받았습니다.

주요 기능 개발

근접 매칭과 기기 알림

두 기기가 만나면 BLE로 상대를 식별하고 LED와 진동 모터로 결과를 알립니다. 기판 소켓과 모듈에 맞춰 배선을 만들고 최종 발표에서 두 키링의 반응을 직접 시연했습니다.

기기에서 앱의 채팅방까지

키링의 만남 결과를 앱에 전달하고 두 사용자가 수락한 뒤 채팅방을 엽니다. 개발 시험에서는 두 기기로 매칭부터 메시지 송수신까지 한 회차를 확인했습니다.

트러블슈팅

만남 기록을 지우면 무반응의 원인도 사라졌다

문제
다시 만난 키링이 조용할 때 저장 건수만으로는 어떤 상대의 알림이 억제됐는지 알 수 없었습니다. 초기화하면 재현 조건도 사라졌습니다.
원인과 해결
상대별 상태를 읽기 전용으로 조회하도록 요청했습니다. 실물에서는 긴 USB 출력 중 일부 줄이 빠져서 앞줄을 처리한 다음 줄을 보내도록 순서를 조정했습니다.
확인 결과
D3.1 보드 한 대에서 전체·상대별 기록과 상태 조회 8회를 끝까지 읽었습니다. 조회 전후 두 저장 영역의 지문도 일치했습니다.

기간2026.10 – 현재

어떤 프로젝트인가요?

BLE 키링으로 주변 사람을 발견하고, 서로 선택한 만남을 기록해 앱과 연결하는 서비스를 만들고 있습니다.

키링·앱·서버가 주고받는 데이터와 복구 조건을 확인했습니다. 실물의 증상과 제약을 전달하고, 부품 배치 스케치와 직접 출력·조립, 저장 상태 및 실제 앱 동작 확인을 맡았습니다.

THE QUESTION

도면에서 들어가던 부품이, 손으로는 조립되지 않았습니다.

기기 안의 부품이 겹치지 않는 것만으로 조립이 보장되지는 않았습니다. 케이블을 꽂는 방향, 버튼을 잡는 순서, 실제 전선이 구부러지는 정도가 설계를 바꿨습니다.

판단하고 바꾼 과정

01

직접 끼워 보며 실패를 관찰

출력한 케이스는 배터리 연결부를 가렸고 버튼을 잡은 채 뚜껑을 닫기 어려웠습니다. 작은 기둥은 휘거나 부러졌고, 암핀 뒤의 전선은 도면의 선처럼 꺾이지 않았습니다.

02

실물 사진과 스케치로 가정 수정

제작한 PCB와 구매 모듈을 유지한다는 조건을 분명히 했습니다. 직접 그린 배치도와 사진으로 배터리를 옆에 세우는 안을 제시하고, 모듈의 회전 방향과 전선이 실제로 나오는 위치를 바로잡았습니다.

03

첫 전체 모듈 조립까지 확인

고정판으로 버튼을 먼저 잡고, 작은 기둥을 넓은 받침으로 바꾸는 방식 등을 반영했습니다. 수정 케이스를 직접 출력한 뒤 처음으로 모든 모듈을 넣어 조립했습니다. 작은 어긋남과 간섭은 다음 개선 항목으로 남겼습니다.

04

신호 수신에서 실제 채팅까지 대조

기기 저장 상태, 앱의 동기화 진행, 서버의 소유 상태를 서로 다른 단계로 확인했습니다. 11월 13일에는 두 키링의 만남 기록이 앱의 양쪽 수락과 채팅방 생성으로 이어지고, 서로 메시지를 보내고 받는 한 사례를 직접 확인했습니다.

직접 조립하고, 실제 사용자 흐름으로 확인

첫 전체 조립

기존 기판·모듈을 케이스 안에 수납

양방향 채팅

실제 두 사용자 흐름 한 사례 확인

케이스의 첫 전체 모듈 조립과 두 키링의 만남 → 양쪽 수락 → 채팅방 생성 → 메시지 송수신을 확인했습니다. 기기 내부의 로그와 화면에서 사용자가 확인하는 결과를 구분해 점검했습니다.

확인 범위

2026년 11월 13일까지 확인한 결과입니다. 일부 케이스 간섭, 다른 보드의 저장·초기화 오류, 기종별 반복 시험과 장시간 부하는 남아 있습니다. 한 사례의 성공을 전체 안정성으로 확대하지 않습니다.

다음 작업에 가져갈 기준

도면의 간섭 검사, 직접 조립, 기기 통신, 앱의 최종 동작은 각각 확인해야 했습니다. 눈앞의 증상과 실제 완료 조건을 연결하면서 다음에 무엇을 시험해야 할지 구체화했습니다.

기록의 근거

11월 12~13일 회고 · 케이스 조립 검증 · 저장 복구와 종단 검증

당시 작업 기록과 보관 자료를 대조해 2026년 11월 15일 포트폴리오로 정리했습니다. 본인의 판단·요구·검증과 팀 전체의 성과를 구분합니다.

어떤 프로젝트인가요?

원하는 시각에 도착할 수 있도록 대중교통의 구간 소요시간을 계산하고, 경로와 출발시각을 안내하는 서비스입니다.

학습과 실시간 연산에 필요한 자료를 수집 담당자와 조율했습니다. 실제 학습 표본과 데이터 연결 상태를 확인하고, 예측 시점에 쓸 수 있는 입력으로 모델을 비교하는 기준을 점검했습니다.

THE QUESTION

모델을 바꾸기 전에, 입력부터 다시 봤습니다.

데이터가 많아도 실제 예측 시점에 쓸 수 없다면 도움이 되지 않았습니다. 성능을 비교하기 전에 데이터가 제대로 연결되는지, 미래의 정보를 미리 사용하는 것은 아닌지 확인했습니다.

판단하고 바꾼 과정

01

모을 수 있는 데이터부터 확인

버스·지하철 위치, 혼잡도, 날씨, 과거 구간 소요시간을 요청한 뒤 수집 담당자와 API 한도와 시간대별 누락을 논의했습니다. 활용 목적과 수집 가능성을 함께 따져 학습·연산에 사용할 자료를 조정했습니다.

02

추가한 정보가 실제로 연결됐는지 확인

승객수 특성을 더한 실험에서 연결률이 0%인 것을 확인했습니다. 입력 열이 있다는 사실과 유효한 값이 결합된 것은 달랐습니다. 키와 결합 결과를 확인하고, 사용·미사용 결과도 비교했습니다.

03

예측하는 순간의 조건으로 맞추기

과거 자료로 학습하는 것과 과거 소요시간 요약을 예측 입력으로 조회하는 일을 구분했습니다. 당시 확보 가능 시점이 검증되지 않은 날씨는 최종 입력에서 제외하고, 시간 순서에 따라 자료를 나눴습니다.

04

평가 기준을 고정한 모델 선택

같은 학습 4,999,590행과 검증 999,894행에서 기준선과 네 후보를 비교했습니다. MAE가 가장 낮은 LightGBM을 선택했지만, 큰 오차를 평가하는 다른 지표에서는 후보별 차이가 있음을 함께 남겼습니다.

같은 검증 자료에서 줄어든 구간 오차

5.68%

같은 검증 자료에서 기준선 대비 평균 절대 오차 감소

999,894행

모델 비교에 사용한 검증 자료

과거 중앙값27.61초
LightGBM26.04초

검증 999,894행 · 평균 절대 오차(MAE), 작을수록 좋음

동일 검증 999,894행에서 과거 중앙값의 평균 절대 오차 27.612696초와 LightGBM의 26.043974초를 비교해 약 5.68% 감소를 확인했습니다. 서로 다른 검증 조건의 숫자를 합쳐 개선율로 표현하지 않았습니다.

확인 범위

위 수치는 과거 버스 정류장 사이의 시간대별 평균 소요시간을 대상으로 한 오프라인 평가입니다. 전체 경로의 실제 도착 정확도나 운영 환경의 성과를 뜻하지 않습니다.

다음 작업에 가져갈 기준

성능 수치뿐 아니라 입력의 가용 시점, 식별자, 예측값의 해석 범위까지 맞아야 서비스에서 사용할 수 있다는 기준을 얻었습니다.

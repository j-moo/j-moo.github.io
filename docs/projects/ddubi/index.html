프로젝트 소개

도착해야 할 시각을 등록하면 대중교통 경로와 출발할 시각을 알려 줍니다. 앱 홈에서는 오늘의 일정과 교통 통제에 따른 우회 안내를 함께 봅니다.

MySQL · Redis · Apache Spark · pandas · NumPy

수집 담당자와 학습에 쓸 수 있는 입력을 정하고 실제 경로 응답을 공식 노선과 대조했습니다. 매핑 코드와 검증기, 모델 학습·실행에는 AI의 도움을 받았습니다.

주요 기능 개발

경로에 버스 운행시간 연결

경로 검색에 표시된 버스를 공식 노선과 연결해야 그 구간의 운행시간을 붙일 수 있습니다. 경로의 노선명뿐 아니라 방향과 정류장 순서를 대조했습니다.

인접 정류장 사이의 시간 예측

실제 예측 시점에 확보할 수 있는 입력을 골랐습니다. 시간 순서로 나눈 동일 검증집합 999,894행에서 구간 시간의 평균 절대 오차는 중앙값 기준선 27.61초, 선정 모델 26.04초였습니다.

트러블슈팅

같은 5002번에 공식 노선이 세 개였다

문제
5002A, 5002B, 5002(예약)가 같은 번호를 사용했습니다. 번호나 좌표만으로 연결하면 다른 버스의 시간이 출발 안내에 들어갈 수 있었습니다.
원인과 해결
예약 표기와 강남역에서 뱅뱅사거리까지의 정류장 순서를 직접 확인했습니다. 검토한 경로·날짜·마스터 버전과 공간 조건이 일치하는 대안에만 공식 ID를 적용했습니다.
확인 결과
개발 경로 4개의 차량 대안 연결이 169/170건에서 170/170건으로 늘었습니다. 기존 169건의 ID는 모두 유지됐습니다.

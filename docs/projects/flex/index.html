프로젝트 소개

소비한 순간을 사진과 금액으로 기록하고 친구와 공유합니다. 한 달이 지나면 내 지출이 어디에 몰렸는지 다시 볼 수 있습니다.

내 역할
공동 기획 · 사용자 흐름 및 기능 검토
팀 · 기간
2인 팀 · 2026.05 기획 · 06 개발
사용 언어
Python · JavaScript
프레임워크
Django REST Framework · Vue 3
도구·기술
Pinia · SQLite

팀원과 서비스를 기획하고 가입부터 첫 소비 기록까지의 흐름을 점검했습니다. 구현 과정에서 발견한 누락은 팀 설계도와 대조하고 AI의 도움으로 수정·검증했습니다.

주요 기능 개발

소비 기록과 친구 피드

사진이나 영상에 금액·카테고리·공개 범위를 붙여 한 건의 소비를 만듭니다. 첫 사용자가 곧바로 기록할 수 있도록 가입 직후 필요한 카테고리 여덟 개의 초기화 조건을 점검했습니다.

월별 소비 분석

분석 결과를 저장해 나중에도 다시 읽을 수 있게 했습니다. 빈 달에는 데이터 부족을 표시하고, 소비 기록이 있는데 외부 분석 호출만 실패하면 규칙 기반 결과를 보여 주도록 검토했습니다.

트러블슈팅

가입이 실패했는데 이메일은 이미 사용 중이었다

문제
계정은 저장됐지만 프로필 생성이 실패하면 같은 이메일로 다시 가입할 수 없었습니다.
원인과 해결
가입 폼, API, DB 모델을 대조해 두 저장의 경계를 찾았습니다. 계정과 프로필 생성을 한 트랜잭션에 묶고 이메일 입력 검사와 DB 유일성 제약을 함께 확인했습니다.
확인 결과
프로필 저장이 실패할 때 계정 생성도 함께 취소되도록 가입 코드에서 확인했습니다.

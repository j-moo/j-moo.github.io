오차가 줄었다. 승객 수가 정말 쓰였을까?

AI에 맡긴 작업
AI와 함께 과거 운행시간을 이용한 입력을 구성하고, 시간순으로 나눈 자료에서 학습 방식을 비교했습니다. 승객 수를 추가한 실험에서는 성능 보고와 실제 학습에 들어간 표본을 다시 대조하도록 했습니다.
내 판단과 검증
승객 수가 학습 행에 얼마나 연결됐는지 확인하니 결합률이 0%였습니다. 결합 오류를 고친 뒤 같은 내부 검증 조건에서 승객 수를 넣은 모델과 뺀 모델을 비교했습니다.

이 비교에서는 승객 수를 넣자 오차가 0.016초 커졌습니다. 승객 수를 개선 요인으로 보고하지 않았습니다. 이후에는 입력 결합률과 실제 학습 행 수를 오차와 함께 확인했습니다.

두 수치는 같은 내부 검증에서 측정한 구간 평균시간 오차입니다. 전체 경로의 도착시각이나 이용자 대상 성능은 별도로 측정해야 합니다.
